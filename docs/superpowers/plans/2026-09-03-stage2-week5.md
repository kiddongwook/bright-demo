# 2단계 5주차 Implementation Plan — 파일럿 직전: 강사 범위 권한 · 반별 휴원 · 재입학 · 학부모 월 달력 · 반별 출결표 · 명부 CSV·내보내기 · 실제 배포

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 영어의 집 파일럿(6주차)에 들어갈 수 있는 상태로 만든다 — 강사가 자기 반만 보고, 반별 휴원이 실제로 반영되고, 퇴원 취소가 되고, 학부모도 달력을 보고, 원장이 반별 출결표를 보고, 명부를 CSV 로 올리고 학원 데이터를 통째로 내려받을 수 있고, 무엇보다 **앱이 실제 주소에 떠 있다**(GitHub Pages `/bright-demo/pwa/`).

**Architecture:** 권한은 헬퍼 하나를 바꿔 좁힌다 — `staff_class_ids()`(원장: 학원 전체 반, 강사: `classes.teacher_id = 나`)와 `staff_student_ids()` 를 만들고, staff 가 쓰던 정책 중 반·학생에 매인 것(출결·학생·수강·공지·할 것·결석·문의·메모·타임라인)은 `is_staff()` 대신 이 집합을 본다. 학원 단위 관리(명부·반·강사·휴원일·FAQ·우리 학원)는 `current_role_() = 'director'` 로. 반별 휴원은 `closedDays()` 가 `{ all, byClass }` 를 돌려주고 `nextClassDays` 가 반마다 자기 휴원을 뺀다. 배포는 빌드 결과를 저장소 `/pwa/` 에 커밋해 Pages 가 그대로 서빙(`base=/bright-demo/pwa/`), 알림톡 링크 `APP_URL` 도 그 주소로.

**Tech Stack:** 1~4주차와 동일. `rls-test` 에 강사 케이스 추가, `manage-test` 에 재입학·반별 휴원 추가. CSV 는 브라우저에서 파싱(외부 라이브러리 없음, 헤더 = `tools/roster.sample.csv` 와 같은 열). 내보내기는 Edge Function `export-academy`(원장 JWT 검증 → 서비스 키로 전 테이블 JSON).

## Global Constraints

- 1~4주차 전역 제약 그대로. 마이그레이션은 `0008_scope.sql` 추가만.
- 강사 범위: **읽기·쓰기 모두** 자기 반(담당으로 지정된 반)과 그 반 학생으로. 담당 반이 없는 강사는 아무것도 못 본다(화면에 "원장님이 담당 반을 지정하면 보여요").
- 원장 전용(강사 불가): 명부 편집·퇴원·재입학, 반·시간표, 강사, 휴원일·특강, FAQ, 우리 학원, 내보내기, CSV 올리기.

- 배포물(`/pwa/`)에 비밀은 없다(anon key 는 공개 키). `.env.local` 은 그대로 gitignore.
- 앱 안의 절대 경로 `/logo/...` 는 모두 `asset()` 헬퍼(`import.meta.env.BASE_URL`)로 — 서브 경로 배포에서 깨지지 않게.

```sql
create or replace function staff_class_ids() returns setof uuid language sql stable security definer set search_path = public as $$
  select c.id from classes c where c.academy_id = current_academy_id()
    and (current_role_() = 'director' or (current_role_() = 'teacher' and c.teacher_id = auth.uid())) $$;
create or replace function staff_student_ids() returns setof uuid language sql stable security definer set search_path = public as $$
  select s.id from students s where s.academy_id = current_academy_id()
    and (current_role_() = 'director' or s.id in (select e.student_id from enrollments e where e.class_id in (select staff_class_ids()))) $$;
-- 예: students_read
drop policy if exists students_read on students;
create policy students_read on students for select using (academy_id = current_academy_id() and (id in (select staff_student_ids()) or id in (select my_student_ids())));
-- attendance_write: 반이 내 범위
drop policy if exists attendance_write on attendance;
create policy attendance_write on attendance for all using (academy_id = current_academy_id() and class_id in (select staff_class_ids())) with check (academy_id = current_academy_id() and class_id in (select staff_class_ids()));
-- notices_write: 강사는 담당 반만, 전체(null)는 원장만
drop policy if exists notices_write on notices;
create policy notices_write on notices for all using (academy_id = current_academy_id() and (current_role_() = 'director' or target_class_id in (select staff_class_ids())))
  with check (academy_id = current_academy_id() and (current_role_() = 'director' or target_class_id in (select staff_class_ids())));
-- classes_write·faqs_write·calendar_write: 원장만
-- calendar unique
do $$ declare c text; begin for c in select conname from pg_constraint where conrelid = 'calendar'::regclass and contype = 'u' loop execute format('alter table calendar drop constraint %I', c); end loop; end $$;
with ranked as (select id, row_number() over (partition by academy_id, date, kind order by id) rn from calendar where class_id is null) delete from calendar where id in (select id from ranked where rn > 1);
alter table calendar add constraint calendar_academy_date_kind_class_key unique nulls not distinct (academy_id, date, kind, class_id);
```
