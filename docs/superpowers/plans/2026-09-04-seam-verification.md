## 2. 적대적 점검 (에이전트 3종, 읽기 전용 + 자기 데이터만 쓰기)

- **보안**: 다른 학원 원장 JWT 로 `issue_invoices`/`record_payment`/`create_invite`/`save_attendance_v2`; 학부모 JWT 로 원장 RPC; 초대 토큰 추측(짧은/잘못된 형식); push_subscriptions 에 남의 user_id 로 insert; 고정 인증번호를 다른 번호에 시도; `my_invoice` 로 남의 자녀 조회.
- **데이터 무결성**: 같은 요청 동시 2회(issue_invoices, record_payment, addCalendar 기간), 퇴원 연쇄(invoices·payments·push_subscriptions 잔존 여부), 학생 삭제 뒤 고아 행, 초대 토큰 만료 정리, outbox 멱등키 충돌.
- **입력**: 제목 2,000자·이모지·줄바꿈이 알림톡 파라미터/푸시 본문에 들어갈 때, 날짜 `2026-02-30`·과거 날짜·시간 `25:00`, 금액 음수·소수·10억, 전화번호 `+82 10-…`, 빈 문자열.

각 에이전트는 **발견 → 재현 스크립트 → 심각도(높음/중간/낮음)** 표로 보고. Fable 이 고칠 것을 정하고 수정 → 재검증 → 배포.
