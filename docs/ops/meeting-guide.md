# 원장 미팅 가이드 — 중·소형 학원용 (2026-09-02)

원칙 셋. **기능을 묻지 않는다**(다 필요하다고 답한다). **최근에 실제로 한 행동**을 묻는다. **화면은 질문 뒤에** 보여준다(보여주면 그 화면 평만 나온다).

---

## 미팅 1 — 알아보기 (30~40분)

### A. 행동 질문 8개 (순서대로)
1. 어제 학원 문 닫고 나서 마지막으로 하신 학원 일이 뭐였어요?
2. **지금 학생 명단이 어디 있어요? 잠깐 보여주실 수 있어요?** ← 가장 중요. 엑셀/종이/카톡이 그 자리에서 나온다
3. 학부모한테 마지막으로 보낸 메시지 좀 보여주세요.
4. 학부모가 제일 자주 묻는 게 뭐예요?
5. 이번 달 미납 있으세요? 그건 어떻게 아셨어요?
6. 최근에 그만둔 학생, 언제 아셨어요? 미리 눈치채셨어요?
7. 전에 쓰던 프로그램 있으세요? 왜 안 쓰게 되셨어요?
8. 학원 운영에 매달 나가는 돈이 뭐가 있어요? (관리 프로그램·문자·홈페이지)

### B. 구조 확인 3개 (설계가 갈리는 것)
- 학생이 **반 두 개**에 동시에 다니는 경우가 있어요? (문법반+독해반)
- **자녀 둘** 보내는 집이 있어요? 아이 폰 없이 부모 번호로 쓰는 학생은요?
- **강사**가 몇 분이세요? 강사도 출결·공지를 직접 하나요?

### C. 실물 5종 받기 (말보다 실물)
| 받을 것 | 어디에 쓰나 |
|---|---|
| 학생 명부 파일 그대로 (엑셀·한글·종이 사진) | 1주차 적재. 컬럼·빈칸·중복이 진짜 구조 |
| 최근 한 달 출석부 사진 | 지각 기준, 보강 표기, 실제 쓰는 기호 |
| 학부모에게 보낸 카톡 캡처 30~50건 | 알림톡 문구 톤, 나중에 원장 말투 |
| **지난달 수강료 청구 내역 1장** | §12 수납 규칙 복원 (할인·일할·교재비) |
| 원장님이 빨간펜으로 고친 답안 5장 | 3단계 첨삭 (지금은 받아만 둔다) |

### D. 데모 시연 순서 (질문·실물 뒤에)
링크 `https://kiddongwook.github.io/bright-demo/` → 입장 화면 아래 **「처음이세요? 눌러보면서 둘러보기」** 15단계. 설명 없이 원장이 직접 누르게 둔다. 끝나면 한 마디만: "원장님 학원 이름으로 이렇게 나갑니다."

### E. 이 미팅에서 정할 것
- 파일럿 조건: **세팅비 면제 + 3개월 무료**, 대신 월 1회 피드백 미팅 + 후기·소개 1건
- 학원 색: 로고 컬러웨이 중 하나 (미정이면 남색)
- 다음 미팅 날짜 — 실물 5종을 들고

### F. 답에 따라 갈리는 길
| 나온 답 | 다음 |
|---|---|
| 2번 엑셀·종이 | 명부 적재가 첫 관문. CSV로 받는다 |
| 3·4번 밤에 카톡이 몰림 | 문의+FAQ가 중심. 알림 시간대 설정 |
| 5번 통장 대조 중 | 수강료 ①단계(청구·납부 확인)를 3단계 맨 앞으로 |
| 7번 "복잡해서 안 씀" | 화면을 더 덜어낸다. 기능 추가 금지 |
| 8번 이미 뭔가에 돈을 씀 | 그 금액이 익숙한 가격대 |

## 미팅 2 — 규칙 정하기 (하기로 한 뒤, 40분)

### 출결
- 몇 분부터 지각? 결석·지각 알림을 **바로** 보낼지, 수업 끝나고 보낼지
- 사전 결석 보강: 토요일 시간대? 자료 대체 허용?
- 휴원일 목록 (이번 학기)

### 공지
- 전체 공지 vs 반별 공지 비율, 보내는 시간대
- 지금 카톡 단톡을 쓰면 → 단톡을 닫을지 병행할지 (병행이면 앱이 진다. 솔직히 말한다)

### 문의
- 자주 묻는 질문 5~10개 (지금 카톡에 반복되는 것)
- 원장 외에 답할 사람이 있나

### 수강료 (§12 규칙 — 청구서 실물 보면서)
- 청구 주기, 납부일, 형제·장기 할인, 중도 등록 일할, 교재비 별도, 환불 규정
- 지금 결제 수단 (이체/카드/현금), 현금영수증 요청 빈도

### 역할·입장
- 강사 계정 필요 여부, 강사가 봐도 되는 것/안 되는 것
- 학생 로그인 필요 여부 (고등은 보통 필요)
- 학부모 번호 등록 동의 문구 확인 (개인정보)

### 우리 학원
- 로고 파일 원본, 학원 색 확정, 한 줄 소개
- 알림톡 발신용 도메인·카카오 채널 개설 동의 (사장님이 대행)

## 계약에 넣을 한 줄들
- 가격: 월 2~3만원(학생 50명, 알림톡 포함) + 세팅비 20~30만원. 파일럿은 위 조건
- 데이터는 학원 것. 언제든 내보내기(CSV) 제공
- 개인정보 처리 위탁: 학원=처리자, BRIGHT=수탁자 (문구는 확인 항목)
- 응답: 영업일 24시간 안에 답한다
- 광고 없음, 앱 설치 강요 없음, 결제는 원장이 켜는 옵션
