# 알림톡 준비 (순서대로 — 앞 것이 끝나야 다음이 된다)

| # | 할 것 | 어디서 | 상태 | 접수번호/메모 |
|---|---|---|---|---|
| 1 | 도메인 확보 (예: bright.app) — 링크 버튼에 등록할 도메인. 학원별이 아니라 **제품 도메인 하나** | 도메인 등록 업체 | ☐ | |
| 2 | 카카오 비즈니스 채널 개설 **"BRIGHT"** — 채널·발신프로필은 운영사(제품) 것 하나로 모든 학원을 태운다. 학원 이름은 문구의 `#{학원}` 변수로 들어간다(`docs/ops/brand.md`) | business.kakao.com | ☐ | 채널 ID: |
| 3 | 발송 대행사 가입 — **솔라피(solapi.com)** 로 정했다 | solapi.com | ☑ | 계정: |
| 4 | 발신프로필 등록 (채널 ↔ 솔라피 연결, 사업자 정보) | 솔라피 콘솔 | ☐ | 프로필 키(`SOLAPI_PF_ID`): |
| 5 | 문자 발신번호 사전등록 (사업자 서류) | 솔라피 콘솔 | ☐ | 번호(`SOLAPI_FROM`): |
| 6 | 템플릿 5개 심사 접수 (아래 문구 그대로) | 솔라피 콘솔 | ☐ | 접수일: |

## 솔라피 준비 (순서대로 — 코드는 이미 다 되어 있다)

붙이는 코드는 끝나 있다(`SMS_PROVIDER=solapi` · `ALIMTALK_PROVIDER=solapi`). 남은 건 계정 쪽 일이다.

1. **발신번호 등록** — 솔라피 콘솔 → 발신번호. 학원 대표번호 말고 **운영사(BRIGHT) 번호 하나**를 등록한다. 통신서비스 이용증명원 등 서류가 필요하고 승인까지 하루 이틀 걸린다.
   승인이 나야 문자가 나간다. 등록 안 된 번호로 보내면 건건이 실패하고, 알림톡의 문자 대체도 **작동하지 않는다**(대체는 등록 발신번호가 있어야 한다).
2. **충전** — 솔라피 콘솔 → 캐시 충전. 선불이다. 잔액이 0 이면 접수가 통째로 거절된다.
   처음엔 만 원이면 시험하기 충분하다. 잔액은 `tools/sms-test.mjs` 가 보낼 때마다 같이 찍어 준다.
3. **API 키 발급** — 솔라피 콘솔 → 개발/연동 → API Key 관리에서 키 쌍을 만든다.
   **API Secret 은 발급 화면에서 한 번만 보인다.** 그 자리에서 `.env.local` 에 넣는다(저장소에 커밋하지 않는다). 잃어버리면 새로 발급받아야 한다.
4. **문자만 먼저 켠다** — 알림톡 심사를 기다리는 동안 문자는 바로 쓸 수 있다.
   ```
   npx supabase secrets set SMS_PROVIDER=solapi SOLAPI_API_KEY=… SOLAPI_API_SECRET=… SOLAPI_FROM=0212345678
   npx supabase functions deploy outbox-send --no-verify-jwt
   ```
5. **한 통 보내 본다** — 자기 번호로 진짜 나간다(요금이 나간다).
   ```
   cd tools && node --env-file=../.env.local sms-test.mjs 01012345678
   ```
   문자를 받았으면 1~3번이 모두 맞은 것이다.
6. **카카오 채널 + 발신프로필** — 위 표 2·4번. 프로필 키(`KA01PF…`)를 받는다.
7. **템플릿 5개 등록·심사** — 아래 문구 그대로. 통과하면 코드마다 `templateId`(`KA01TP…`)가 나온다.
8. **알림톡을 켠다**
   ```
   npx supabase secrets set ALIMTALK_PROVIDER=solapi SOLAPI_PF_ID=KA01PF… \
     SOLAPI_TEMPLATES='{"NOTICE_NEW":"KA01TP…","NOTICE_REMIND":"KA01TP…","INQUIRY_ANSWERED":"KA01TP…","MAKEUP_CONFIRMED":"KA01TP…","ATTENDANCE":"KA01TP…"}'
   npx supabase functions deploy outbox-send --no-verify-jwt
   ```
   다섯 개가 한꺼번에 통과하지 않아도 된다. `SOLAPI_TEMPLATES` 에 없는 코드는 **그 줄만 문자로 나간다**(사유가 로그에 남는다) — 알림이 멈추지 않는다. 대신 그 종류는 문자 요율로 나간다.

세부(비밀값 표, 학원별 키, 오류 읽는 법, 수신 결과 콜백을 나중에 붙이는 법)는 `docs/ops/outbox.md` 의 "솔라피(Solapi) 붙이기".

## 템플릿 (본문 없음 — 광고성 거절 회피)

| 코드 | 문구 | 버튼(웹링크) |
|---|---|---|
| NOTICE_NEW | [#{학원}] 새 공지가 올라왔어요. #{제목} | 앱에서 보기 → https://<도메인>/?l=#{토큰} |
| NOTICE_REMIND | [#{학원}] 아직 확인하지 않은 공지가 있어요. #{제목} | 앱에서 보기 → https://<도메인>/?l=#{토큰} |
| INQUIRY_ANSWERED | [#{학원}] 문의에 답변이 도착했어요. | 답변 보기 → https://<도메인>/?l=#{토큰} |
| MAKEUP_CONFIRMED | [#{학원}] #{날짜} 결석 보강이 정해졌어요. #{보강} | 확인하기 → https://<도메인>/?l=#{토큰} |
| ATTENDANCE | [#{학원}] #{학생} 오늘 출결이 기록됐어요. #{상태} | 확인하기 → https://<도메인>/?l=#{토큰} |

### 변수

| 변수 | 어디서 오나 | 쓰는 템플릿 |
|---|---|---|
| #{학원} | `academies.name` — 알림 트리거가 params 에 넣는다 | 5개 전부 |
| #{제목} | `notices.title` | NOTICE_NEW · NOTICE_REMIND |
| #{날짜} | `absence_requests.date` (MM/DD) | MAKEUP_CONFIRMED |
| #{보강} | 보강 시각 또는 "자료로 대체" | MAKEUP_CONFIRMED |
| #{학생} | `students.name` | ATTENDANCE |
| #{상태} | 지각 / 결석 | ATTENDANCE |
| #{토큰} | 발송할 때 새로 나오는 링크 토큰 (7일) | 버튼 URL 5개 전부 |

### 변수가 솔라피로 가는 모양
`_shared/alimtalk.ts` 의 `solapiVariables()` 가 우리 `params` 의 칸 이름을 `#{…}` 로 감싸서 그대로 보낸다 — `params['제목']` → `"#{제목}": "모의고사 특강"`.
그래서 **템플릿의 변수 이름은 위 표의 한글 이름과 글자 하나까지 같아야 한다.** 심사 때 이름을 바꿨으면 `TEMPLATES` 의 칸 이름도 같이 바꾼다.
`#{토큰}` 은 params 에 없다 — 발송 때 만든 버튼 URL(`…/?l=<토큰>`)에서 토큰만 뽑아 넣는다.
값은 보내기 전에 칸마다 길이를 자른다(`PARAM_MAX` — 학원 40자, 제목 80자 …). 심사 때 정한 변수 길이 제한이 이보다 짧으면 `PARAM_MAX` 를 그 값으로 내린다.

템플릿은 학원마다 새로 심사받지 않는다 — BRIGHT 발신프로필 아래 5개를 한 번만 등록하고, 학원 이름은 #{학원} 변수로 채운다(앞머리 대괄호 안이 변수여도 되는지, 학원마다 발신프로필을 따로 파야 하는지는 **심사 접수 전에 대행사에 확인**할 것).

## 확인 항목 (솔라피 콘솔에서 / 문의로)
- 채널 인증 요건, 발신프로필 발급 조건, 링크 버튼 도메인 등록 방식
- 알림톡·문자 건당 요율, 선불 충전 단위 — 대체 문자는 버튼 URL(토큰 32자)이 붙어 사실상 늘 **LMS** 다. LMS 요율로 잡을 것
- 앞머리 대괄호 안이 변수(`[#{학원}]`)여도 심사가 통과하는지 — 안 되면 문구를 `#{학원} 새 공지가…` 꼴로 바꾸고 `TEMPLATES` 도 같이 고친다
- 템플릿 변수 길이 제한 (#{제목} 최대 글자 수) → `_shared/alimtalk.ts` 의 `PARAM_MAX`
- 수신 결과 웹훅은 **지금 붙이지 않았다.** 접수까지만 우리가 알고 도착 여부는 솔라피 콘솔에서 본다.
  나중에 붙일 때 문자 대체가 두 겹이 되는 자리가 있다 — `docs/ops/outbox.md` "콜백(수신 결과)은 나중에" 를 읽고 하나만 고른다.

## 문구 원본
템플릿 문구는 `supabase/functions/_shared/alimtalk.ts` 의 `TEMPLATES` 와 글자 하나까지 같아야 한다. 심사 뒤 바꾸면 양쪽을 같이 바꾼다. 버튼 URL 의 `?l=` 뒤 토큰은 발송 때마다 새로 나오고 7일 뒤 만료된다.
