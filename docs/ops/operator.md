# BRIGHT 운영 (사장님 화면)

학원을 만들고, 원장님께 링크를 보내고, 상태를 보고, 필요하면 멈추거나 지운다.
전부 앱 안 **운영** 화면에서 한다 — 명령어는 첫 운영자를 등록할 때 딱 한 번만 쓴다.

앱 주소: https://kiddongwook.github.io/bright-demo/pwa/

---

## 0. 첫 운영자 등록 (한 번만)

운영자는 학원 소속이 아니다. 그래서 앱 안에서는 운영자를 늘릴 수 없다 — 서비스 키로만 등록한다.

```
cd tools
node --env-file=../.env.local set-operator.mjs 01012345678 "홍길동"
```

- 그 번호로 앱에서 **인증번호 로그인**하면 BRIGHT 운영 화면이 열린다. 명부에 없어도 된다.
- 사장님이 어느 학원의 원장이기도 하면 둘 다 된다 — 역할 고르기 화면에 "BRIGHT 운영자" 가 하나 더 뜬다.
- 목록 보기: `node --env-file=../.env.local set-operator.mjs --list`
- 해제: `node --env-file=../.env.local set-operator.mjs 01012345678 --remove`
  (계정과 학원 소속은 그대로 둔다. 운영 화면만 사라진다.)

---

## 1. 학원 만들기 → 원장님께 링크 보내기

**운영 → 학원 만들기** 에서 이름·주소(slug)·원장 이름·원장 번호·강조색을 넣는다.
누르면 학원·원장 명부·초대 링크가 한 번에 생긴다 (예전 `tools/new-academy.mjs` 와 같은 일).

- 주소(slug)는 영어 소문자·숫자·붙임표만, 2~40자. 이미 있으면 "이미 쓰는 주소예요".
- 원장 번호는 휴대폰 번호만 (010 은 11자리).
- 만들고 나면 **초대 링크가 화면에 한 번만** 나온다. 그 자리에서 복사해 원장님께 카톡으로 보낸다.
  - 링크 모양: `…/pwa/?a=<slug>&i=<32자리>`
  - **7일** 안에 눌러야 한다. 누르면 원장님은 인증번호 없이 바로 원장으로 들어온다.
  - 링크를 잃어버렸거나 기간이 지났으면 **학원 상세 → 초대 링크 다시 만들기**. 옛 링크는 그 순간 죽는다.

보낼 문구 예시:

> 원장님, BRIGHT 앱입니다. 아래 링크를 누르시면 바로 들어오세요 (7일 안에).
> https://…/pwa/?a=…&i=…
> 처음 들어오시면 학원 로고와 반·학생 명부를 넣으시면 됩니다.

이어서 안내할 것: 로고(설정 → 학원 정보 → 로고), 명부 CSV 넣기(원장 화면의 명부 → 한꺼번에 넣기).

## 2. 학원 목록에서 보는 숫자

| 칸 | 뜻 |
|---|---|
| 학생 | 지금 다니는 학생 (퇴원 제외) |
| 들어온 학부모 M/T | T = 명부의 학부모 번호 수, M = 그중 앱에 들어온 사람 (같은 번호가 자녀 둘이면 한 사람) |
| 알림 못 받는 K | 앱에 들어왔지만 살아 있는 푸시 구독이 없는 학부모·학생 |
| 이번 달 청구 / 납부 | 이번 달(한국 시간) 청구서 수 / 그중 완납 (면제는 안 센다) |
| 발신 | 그 학원의 문자 발신 모드 (`console` = 아직 안 나감 / `http` = 대행사로 나감) |

**"알림 못 받는" 이 많으면** 원장님께 "학부모님들께 앱 설치 + 알림 켜기 안내" 를 부탁한다.
문자 대행사가 아직 안 붙어 있으면(`console`) 앱 밖으로는 아무것도 안 나간다 — 그게 정상이다.

## 3. 문자 발신 모드·발신키

**학원 상세 → 발신 설정.**

- `console` — 문자·알림톡이 실제로 안 나간다(로그만). 대행사 계약 전 기본값.
- `http` — 대행사 REST 로 나간다. 학원마다 발신키를 따로 쓸 때 여기에 그 학원 키를 넣는다.
- 키를 안 넣으면 전역 키(Edge 비밀값 `ALIMTALK_SENDER_KEY` / `SMS_SENDER_KEY`)로 나간다.
- 모드만 바꾸면 키는 그대로 남는다. 키 칸을 비우고 저장하면 키가 지워진다(전역 값으로 되돌아감).

### 키가 어떻게 지켜지나 (솔직하게)

**암호화가 아니다.** 저장은 평문이고, 읽는 길만 좁혀 두었다.

- `academy_settings` 표는 RLS 를 켜 두고 정책이 하나도 없다 → 로그인한 어떤 사용자도 직접 못 읽는다.
- 운영자는 `op_get_sms()` 로 **마스킹된 값(`****1234`)** 만 본다. 원문은 어떤 화면에도 안 나간다.
- 발송기(Edge `outbox-send`)만 `academy_sms_key()` 로 원문을 가져간다 — `service_role` 전용이다.

왜 pgcrypto 로 안 묶었나: 대칭키를 넣을 자리(커스텀 GUC)가 Supabase 에 없다. 세션마다 비밀값을
`set_config` 로 심으면 그 값이 연결 풀과 로그에 남아 오히려 더 나쁘다.
그래서 **데이터베이스를 통째로 가져간 사람에게는 보인다** — 그 위험은 `SUPABASE_SERVICE_KEY` 와 같은 등급이고,
대행사 키는 언제든 대행사 화면에서 갈아 끼울 수 있다.

## 4. 잠금 (이용 정지)

**학원 상세 → 이용 정지.** 요금 미납·계약 종료 때 쓴다.

- 잠긴 학원은 **로그인이 막힌다** — 인증번호도, 초대 링크도 `academy_locked` 로 거절된다.
  앱은 "이용이 정지된 학원이에요" 화면을 띄운다.
- 알림톡·문자 버튼의 링크(`?l=…`, Edge `link-login`)와 인증번호 발송(`otp-send`)도 잠금을 본다(4차 묶음) — 문자는 나가지 않고 403 `academy_locked`.
  잠근 학원에는 새 알림이 거의 안 생기고(원장이 못 들어온다) 옛 링크는 7일이면 죽는다 — 다음 판에서 막는다.
- 이미 열려 있는 앱의 세션도 그 자리에서 막힌다(0030): 잠그는 순간 그 학원 소속의 현재 역할이 풀리고, `current_membership()` 이 잠긴 학원을 null 로 보므로 RLS·RPC 가 모두 빈 결과를 돌려준다. 역할 선택에서 잠긴 학원을 고르면 `academy_locked` 안내가 뜬다.
- **데이터는 그대로 남는다.** 잠금을 풀면 아무 일도 없었던 것처럼 돌아온다.
- 번호가 학원 둘에 있는 사람(학원 A 의 학부모이면서 학원 B 의 강사)은 **잠긴 쪽만 빠진다.**
  남는 학원이 하나도 없을 때만 로그인이 거절된다.

---

## 5. 데이터 내려받기

**학원 상세 → 데이터 내려받기.** 학원의 모든 표를 JSON 한 파일로 받는다
(반·학생·명부·출결·결석·공지·문의·할 것·메모·달력, 그리고 이름·번호). 학원이 나갈 때 이관용으로 준다.

지우기 **전에** 반드시 한 번 받아 둔다. 지운 뒤에는 되돌릴 길이 없다.

---

## 6. 학원 지우기

**학원 상세 → 학원 지우기.** 확인을 위해 **주소(slug)를 손으로 다시 입력**해야 버튼이 열린다.

지워지는 것:
- 학원과 딸린 모든 표(반·학생·명부·출결·청구서·공지·알림·초대 토큰·학원 설정) — 되돌릴 수 없다.
- 저장소의 로고(`logos/<학원id>/`)와 공지 사진(`notices/<학원id>/`).

남는 것:
- 사람의 로그인 계정. 그 사람이 다른 학원에도 있으면 그 학원은 그대로 쓴다.
  다른 데가 없으면 계정만 남고 아무 데도 못 들어간다(명부가 없으므로 인증번호도 안 나간다).

순서: **파일 먼저, 그다음 표.** (반대로 하면 학원 id 를 잃어 사진을 못 찾는다.)

## 7. 문제가 생겼을 때

| 증상 | 볼 곳 |
|---|---|
| 원장님이 "링크가 안 열려요" | 7일이 지났나 · 다시 만들기를 눌러 새 링크를 보냈나 · 학원이 잠겨 있지 않나 |
| 원장님이 "인증번호가 안 와요" | 발신 모드가 `console` 이면 실제로 안 간다. 초대 링크를 쓰거나 대행사를 붙인다 |
| 운영 화면이 안 보인다 | `set-operator.mjs --list` 에 그 번호가 있나 · Edge(`otp-send`·`otp-verify`)가 최신인가 |
| 숫자가 이상하다 | 목록 숫자의 뜻은 위 2번 표. "알림 못 받는" 은 푸시 구독 기준이다 |
